<objective>
Build a fuzzy product matching service and backend endpoint that, given a product URL and store, finds the same product listed on other stores. This enables the multi-vendor comparison feature.

Purpose: Users need to compare the same product across stores. The existing ranking algorithm is asymmetric (query-to-product) and not suitable for product-to-product matching. fuse.js provides symmetric fuzzy matching with configurable thresholds.

Output: Backend `/matches` endpoint + reusable `product-matching.service.ts`.
</objective>

    **Step 2: Create `backend/src/services/product-matching.service.ts`**

    This file exports a `findMatchingProducts` function that takes a source product and an array of candidate products, and returns only the ones that match the source product name.

    Interface:
    ```typescript
    import Fuse from 'fuse.js';
    import { ScrapedProduct } from './scraper.service';

    export function findMatchingProducts(
      sourceProduct: { name: string; url: string },
      searchResults: ScrapedProduct[],
      threshold: number = 0.3
    ): ScrapedProduct[]
    ```

    Implementation:
    1. Filter out the current product by URL: `searchResults.filter(p => p.url !== sourceProduct.url)`
    2. Filter out accessories using the existing `ACCESSORY_KEYWORDS` list from ranking.ts. Import or duplicate the list. Check if the product name (lowercased) contains any accessory keyword as a whole word. If so, exclude it.
    3. Clean product names by stripping store-specific suffixes (regex-based, case-insensitive):
       - List: `['free delivery', 'official warranty', 'best price', 'cash on delivery', 'genuine product', 'brand new', 'imported', 'local stock', 'online shopping', 'buy now', 'order now', 'limited stock', 'best deals', 'daraz', 'telemart', 'shophive']`
       - Strip pattern: `\s*[-|\\u2013|,]?\s*{suffix}` (case-insensitive)
    4. Create a cleaned array with `cleanedName` added to each product
    5. Use fuse.js:
       ```typescript
       const fuse = new Fuse(cleanedResults, {
         keys: [{ name: 'cleanedName', weight: 1.0 }],
         threshold,
         includeScore: true,
         minMatchCharLength: 4,
       });
       const sourceCleaned = cleanProductName(sourceProduct.name);
       const matches = fuse.search(sourceCleaned);
       ```
    6. Return matches sorted by price ascending (for Best Value -- cheapest first):
       ```typescript
       return matches.map(m => m.item).sort((a, b) => a.price - b.price);
       ```

    Export the `cleanProductName` function as well (it will be useful for debugging and testing).

    Export a `STORE_SUFFIXES` constant for reference.

    IMPORTANT: Do NOT import from ranking.service.ts or webapp/utils/ranking.ts. Duplicate the ACCESSORY_KEYWORDS list here to avoid cross-boundary coupling. The matching service should be self-contained.

    The endpoint must:
    1. Validate that both `url` and `store` query params are present; return 400 if not
    2. Check cache: `cacheGet('matches:' + url)`. If cache hit, return immediately.
    3. Scrape the source product to get its name: `scrapeProductDetail(url, store)`
    4. If scrape fails (returns null), return 404 with `{ error: 'Could not scrape source product' }`

    6. Search all stores: `searchAllStores(searchQuery)`
    7. Apply fuzzy matching: `findMatchingProducts({ name: productName, url }, allResults)`
    8. Cache results: `cacheSet('matches:' + url, matches, 3600)` (1hr TTL)
    9. Return: `{ matches: [...], sourceProduct: { name, store, price, imageUrl }, count: matches.length }`

    IMPORTANT placement: This route MUST be placed BEFORE the `/:id` route to avoid Express matching "matches" as an `:id` param. It should go after the existing `/trending` and `/product` routes but before `/:id`.

    Helper function to build search query from product name:
    ```typescript
    function buildSearchQuery(productName: string): string {
      // Take first meaningful words (skip store suffixes, stop at storage spec)
      const words = productName.split(/\s+/);
      const result: string[] = [];
      for (const word of words) {
        if (result.length >= 5) break; // Cap at 5 words
        if (/^\d+(GB|TB)$/i.test(word)) break; // Stop at storage spec
        if (word.length < 2) continue;
        result.push(word);
      }
      return result.join(' ');
    }
    ```
